## M1 — 抽象变分核心

建立不依赖具体模型的 Galerkin 层：

- 有界且强制的双线性形式；
- 弱解和 Galerkin 解的规格；
- Galerkin 正交性；
- Céa 拟最优性定理；
- 具体的可编译示例；
- 数学语义审查和蓝图声明链接。

本里程碑不需要网格或具体 PDE。

## M2 — Poisson 连续问题

- 通过 RFC 0001 选择 Sobolev 空间表示；
- 在明确的区域和边界假设下定义 Poisson 弱问题；
- 证明或复用所需的 Poincaré 和 Lax–Milgram 结果；
- 实例化抽象 Galerkin 接口并推出拟最优估计。

## M3 — 二维 P1 单元

- 通过 RFC 0002 选择网格表示；
- 定义参考三角形、仿射映射和节点基函数；
- 建立形状正则网格族和分片线性空间；
- 证明协调性和基本节点性质。

## M4 — 第一条完整有限元误差定理

- 建立所需插值和 Bramble–Hilbert 结果；
- 在明确的正则性和网格假设下证明
  \(\|u-u_h\|_{H^1(\Omega)} \le C h |u|_{H^2(\Omega)}\)；
- 公开主定理的假设、声明链接和公理审计结果。

## M5 — 按研究方向扩展

根据当前研究需要选择，而不是按原书顺序推进：

- Aubin–Nitsche 对偶方法；
- Strang 引理和非协调方法；
- inf-sup 理论和 Fortin 插值；
- 后验估计与自适应方法；
- 迭代法和多重网格求解器；
- 弹性应用。

只有主要结果无占位构建、通过公理审计、接受数学语义审查并被下游实际使用后，
相应里程碑才算完成。

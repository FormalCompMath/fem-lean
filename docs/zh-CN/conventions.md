# Lean 项目规范

[English version](../conventions.md)

除非有书面记录的项目特殊理由，FemLean 遵循当前 Mathlib 规范。

## 命名与来源对应

- 在适当的 `FemLean` 命名空间中使用清晰的声明名；
- 在蓝图或 PR 中记录原书版本、章节和页码，而不是建立按章节编号的 Lean 目录；
- 通过 docstring 和蓝图链接让数学定义易于发现；
- 不大段复制受版权保护的原书内容。

## 导入与文件

- 导入提供所需接口的最小模块；
- 内部模块不要导入公共根模块 `FemLean.lean`；
- 将可独立复用的结果放在不同模块；
- 避免巨型通用工具文件。

## 记法与自动化

- 优先使用 scoped 记法，并在下游局部打开作用域；
- 只有规范构造才添加全局类型类实例；
- 实验和竞争性表示使用局部实例；
- 只有重写方向有助于形成一致简化范式时，才添加全局 `simp` 属性；
- 避免不必要的 coercion 和遮蔽定理陈述的自动化。

## 陈述与示例

- 重要数学假设应在陈述或显式结构中可见，不要藏进无关变量；
- 添加能够使用新接口的可编译示例；
- 不使用自定义公理作为 `main` 上的接口占位符；
- 临时未完成证明只能存在于 Draft PR。

## 重构与依赖

- 将保持行为不变的重构与数学修改分开；
- 在独立 PR 中更新 Lean、Mathlib 和文档依赖；
- 通过 Lake manifest 固定依赖版本，并记录升级原因。

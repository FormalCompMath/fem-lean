# RFC 0004：有限元接口

[English version](../../rfcs/0004-finite-element-interface.md)

- 状态：草稿
- 决定：待定
- 目标里程碑：M3

## 问题

选择单个有限元（Ciarlet 三元组 $(K, P, \Sigma)$）、参考元到物理元变换，以及从
局部自由度到全局离散空间衔接的 Lean 表示。

M3 优先落地二维仿射 $P_1$ 三角形单元，同时接口应避免在后续里程碑新增高阶
Lagrange 单元（$P_k$）、非协调单元（Crouzeix–Raviart）、$H(\operatorname{div})$
单元（Raviart–Thomas）或泛化至 $d$ 维单形时被迫重写核心。

## 下游用途

- **M3**：证明二维 $P_1$ 单值性、节点基取值恒等式和公共边上的迹相等。
  全体节点值重建到 $H^1(\Omega)$。记 $D_h^0$ 为自由顶点坐标空间，在边界顶点补零
  即得到边界零节点数据。证明 $R_h^0:D_h^0\hookrightarrow H_0^1(\Omega)$ 为线性单射。
  `Models/Poisson` 以其像为离散子空间，实例化 `Assembly/` 的坐标等价定理。
- **M4（`Approximation/`）**：多项式再现、参考元插值算子与仿射拉回缩放。
- **M5（`FiniteElement/`）**：高阶 $P_k$、边均值自由度（CR）、法向通量矩（带
  Piola 变换的 RT）及 $d$ 维泛化。

## 需要回答的问题

- 如何封装局部形函数空间 $P$ 与自由度求值映射 $\Sigma : P \to (\iota \to \mathbb{R})$，
  使单值性直接给出线性等价 `P ≃ₗ[ℝ] (ι → ℝ)` 与形函数基？
- 局部形函数应定义在环境欧氏空间上（作为多项式/仿射映射限制到 $K$），还是直接
  定义在子类型 `K` 上？
- 参考元到物理元的变换应如何分层，既能在 M3 保持标量仿射拉回简洁，又能为 M5 的
  Piola 变换留出接口而不造成过度设计？
- 局部到全局自由度的收集（gather）如何同时自然衔接全局 Sobolev 协调性
  （`FiniteElement/GlobalSpace`）与矩阵装配（`Assembly/`）？

## 需要制作原型的方案

1. 轻量级结构体 `FiniteElement`，封装参考几何、有限维局部空间、线性自由度映射
   及单值性等价，首先实例化二维 $P_1$；
2. 以单元类型与自由度索引类型为参数的类型类接口；
3. 先写具体的二维 $P_1$ 定义，等引入第二类单元时再提取抽象层。

## 必要原型

接受方案之前，完成二维 $P_1$ 三角形实例原型，验证节点基的 Kronecker-delta 性质、
陈述向物理三角形的仿射拉回，并勾勒边均值自由度（Crouzeix–Raviart）或 $P_2$ 边
中点自由度如何接入同一接口。

用[单位正方形的两种剖分](0002-mesh-representation.md#同一区域上的两种剖分)检验两个全局空间。
全体顶点赋值 1 应重建出常数 1，边界值也为 1。在四三角形网格上，自由顶点赋值 1、
边界补零应得到中心帽函数，其在所有边界边上均为零。Poisson 装配验收便有一个非零试探函数。
